# 🚀 Project Overview

Smart-College-Assistent is an **AI-powered intelligent chatbot** built using:

- Flask (Backend)
- Sentence Transformers (Semantic NLP)
- Scikit-learn (Cosine Similarity)
- Dynamic Context Handling
- Modern Responsive UI

This chatbot provides real-time information about:

- 🎓 Admissions  
- 📄 Documents  
- 💰 Fees & Scholarships  
- 🏫 Branches  
- 💼 Placement & Internship  
- 💻 Projects  
- 📚 Exams & Results  
- 🏠 Hostel & Facilities  
- 🎯 Interview & Resume  
- 😊 Motivation

# 🧠 AI Architecture

```
User Input
     ↓
Text Cleaning
     ↓
Sentence Transformer Embedding
     ↓
Cosine Similarity Matching
     ↓
Intent Selection
     ↓
Confidence Threshold Check
     ↓
Context Management
     ↓
Response + Smart Follow-Up Suggestions
```

# ⚙ Installation Guide

## 1️⃣ Clone Repository

```bash
git clone https://github.com/yourusername/smart-college-assistent.git
cd smart-college-assistent
```

## 2️⃣ Create Virtual Environment

```bash
python -m venv venv
venv\Scripts\activate
```

## 3️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

## 4️⃣ Run Application

```bash
python app.py
```

Open in browser:

```
http://localhost:5000
```
